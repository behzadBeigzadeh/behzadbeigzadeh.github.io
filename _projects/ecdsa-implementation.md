An educational Python implementation of the Elliptic Curve Digital Signature Algorithm (ECDSA), built to make the steps behind digital signatures visible.

### What the project implements

- Point addition, point doubling, and scalar multiplication on the secp256k1 curve.
- Private/public key generation, message signing, and signature verification without a cryptographic library.
- SHA-512 message hashing and verification examples for original and modified messages.

The focus is understanding the underlying cryptographic operations through an educational implementation.
